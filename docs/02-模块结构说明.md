# 02 模块结构说明

> 适用场景：搞清楚"某个功能/代码在哪个模块"、项目是如何组织的。

## 根目录结构

```
jeesite/
├── pom.xml                  # 根聚合 pom（modules 清单）
├── parent/                  # 父 pom：统一管理版本号与依赖
├── common/                  # 通用工具库（jeesite-common，jar）
├── common/static/           # 静态资源库（js/css/images，jar）
├── modules/                 # 业务功能模块聚合
├── web/                     # 传统端 Web 启动工程（HTML5+jQuery）
├── web-vue/                 # Vue 分离端 Web 启动工程
├── web-api/                 # 纯 API 接口服务启动工程（无登录界面）
├── web-fast/                # 快速体验工程（H2 免初始化）
├── web-mini/                # 极简内核服务（1 秒启动）
├── web-ai/                  # AI 智能模块启动工程
├── bin/                     # 根级构建/部署脚本
├── docker-compose.yml       # Docker 一键部署（官方 jeesite 镜像）
├── docker-compose-mysql.yml # Docker + MySQL 一键部署
├── README.md
├── terms.md                 # 服务条款
└── LICENSE
```

根 pom 模块清单：`parent`、`common`、`common/static`、`modules`、`web`、`web-ai`、`web-api`、`web-fast`、`web-mini`、`web-vue`

## Maven 模块详解

### 基础模块

| 模块 | artifactId | 说明 |
|---|---|---|
| parent | jeesite-parent | 父 pom，集中定义版本属性、公共依赖、插件 |
| common | jeesite-common | 通用工具库：ID 生成、加解密、图片、Excel、二维码、拼音、邮件等（包 `com.jeesite.common.*`） |
| common/static | jeesite-common-static | 前端静态资源（jquery、bootstrap 等）打包为 jar 提供 |

### 业务模块（modules/ 聚合）

| 模块 | artifactId | 说明 |
|---|---|---|
| core | jeesite-module-core | **核心模块**：组织/用户/权限（sys）、区域（area）、业务示例（biz）、文件管理（file）、消息（msg）、系统参数（config） |
| app | jeesite-module-app | 移动端 App 模块（接口 + 推送） |
| cms | jeesite-module-cms | 内容管理系统（CMS）：栏目、文章、站点 |
| ai | jeesite-module-ai | AI 智能模块：Spring AI + RAG 知识库 + 大模型对话（支持 Ollama/DeepSeek/通义千问，向量库 Chroma/PGVector/ES/Milvus） |
| test | jeesite-module-test | 测试/演示模块 |

> 注：web-api 还通过 Maven 依赖了 dbm（数据库管理）、swagger（接口文档）、filemanager、filepreview（文件预览）等模块，这些由远程依赖引入。

### Web 启动工程（每个都是独立可运行的应用）

| 模块 | packaging | finalName | 入口类 | 端口 | context-path | 用途 |
|---|---|---|---|---|---|---|
| web | war | web | `com.jeesite.modules.Application` | 8980 | `/js` | 传统全栈端（Thymeleaf + jQuery 界面） |
| web-api | war | web | `com.jeesite.modules.ApiApplication` | 8980 | `/js` | **纯 API 接口服务**，关闭登录页和主框架页，供 Vue 前端调用 |
| web-vue | war | web | — | 8980 | `/js` | 默认展示 Vue 分离端界面，关闭 HTML+jQuery 界面 |
| web-fast | war | web | — | 8980 | `/` | 快速体验工程，内置 H2 数据库自动初始化，账号 system/admin |
| web-mini | war | web | — | — | — | 极简内核，1 秒启动，不初始化界面和权限，可做内部数据处理服务 |
| web-ai | war | web | — | — | — | AI 智能模块启动工程（依赖 modules/ai） |

> war 包为可执行包（`spring-boot:repackage` 内置 Tomcat），用 `java -jar web.war` 即可启动，无需单独装 Tomcat。

## 依赖关系速查

```
web-api（war）
 └─ jeesite-module-core / dbm / test / swagger / cms / app / filemanager / filepreview
     └─ jeesite-common（工具库）
     └─ parent（版本管理）
```

## 核心代码位置

| 想找什么 | 位置 |
|---|---|
| 用户/角色/菜单/机构/公司/岗位 实体与业务 | `modules/core/src/main/java/com/jeesite/modules/sys/` |
| 系统参数、地区、业务示例 | `modules/core/.../modules/{config,area,biz}/` |
| 文件管理 | `modules/core/.../modules/file/` |
| 消息 | `modules/core/.../modules/msg/` |
| 通用工具类 | `common/src/main/java/com/jeesite/common/` |
| 各模块启动配置 | `web*/src/main/resources/config/` |
| 各模块运行脚本 | `web*/bin/` |
| 数据库建库脚本 | `modules/core/db/{mysql,postgresql,...}/` |
