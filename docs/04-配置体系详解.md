# 04 配置体系详解

> 适用场景：改端口、数据库、缓存、邮件、文件上传等配置。

## 配置文件位置

```
web*/src/main/resources/
├── application.yml            # 主配置（各模块各有一份，内容相同）
├── application-prod.yml       # 生产环境覆盖配置（MySQL 示例）
├── config/                    # （config 目录下也有 application.yml，两者等价，Spring Boot 自动加载）
│   ├── application.yml
│   └── application-prod.yml
└── logback.xml                # 日志配置
```

各 web 模块的 `application.yml` **内容基本一致**，差异在模块相关配置（如 web-fast 默认 H2）。

## 核心配置节一览

### 1. 服务器（server）

```yaml
server:
  port: 8980
  servlet:
    context-path: /js        # web-fast 为 ~（根路径）
  tomcat:
    # uri-encoding: utf-8 等
```

### 2. 数据库连接（jdbc）—— 部署必改

```yaml
jdbc:
  # PostgreSQL（默认）
  type: postgresql
  driver: org.postgresql.Driver
  url: jdbc:postgresql://127.0.0.1:5432/jeesite_v5
  username: root
  password: 123456
  testSql: SELECT 1

  # MySQL（application-prod.yml 示例）
  # type: mysql
  # driver: com.mysql.cj.jdbc.Driver
  # url: jdbc:mysql://127.0.0.1:3306/jeesite?useSSL=false&allowPublicKeyRetrieval=true&useUnicode=true&characterEncoding=utf-8&zeroDateTimeBehavior=CONVERT_TO_NULL&serverTimezone=Asia/Shanghai
  # username: jeesite
  # password: jeesite
```

> 生产环境还支持通过环境变量覆盖：`MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_DBNAME`、`MYSQL_USERNAME`、`MYSQL_PASSWORD`（见 application-prod.yml 注释）。

### 3. 数据源（spring.datasource）

Spring Boot 数据源配置（`spring.datasource.url/username/password`）与上述 `jdbc.*` 二选一，官方以 `jdbc.*` 为准（由 JeeSite 自研连接池封装读取）。

### 4. Redis（可选，缓存 L2）

```yaml
spring:
  redis:
    host: 127.0.0.1
    port: 6379
    # ssl 等
```

### 5. 缓存（j2cache）

两级缓存：本地 Caffeine + Redis。`j2cache` 相关配置节控制缓存模式与分区。

### 6. 文件上传/存储（file 相关节）

文件保存目录、允许类型、大小上限等。

### 7. 邮件（spring.mail）

SMTP 服务器、账号密码、ssl 端口（示例 `smtp.163.com` / `sslSmtpPort: 994`）。

### 8. 短信网关

短信服务商配置（AccessKeyId、AccessKeySecret、签名等）。

### 9. 其它

- `shiro`：会话/权限配置
- `logging` / `logback.xml`：日志级别与文件输出
- `mybatis`：mapper 扫描与配置
- `swagger`：接口文档开关
- `jeesite.*`：平台自身开关（如 apiMode 等）

## 多环境配置机制

- 默认加载 `application.yml`
- 启动时加 `--spring.profiles.active=prod` 加载 `application-prod.yml` **覆盖**主配置
- **注意**：`application-prod.yml` 默认示例是 MySQL。本项目用户强制 PostgreSQL，**部署 web-api 时不要加 `--spring.profiles.active=prod`**，直接使用默认 PostgreSQL 配置。

## 日志配置（logback.xml）

- 默认输出到控制台 + 文件（`logs/` 目录，按天滚动）
- 日志级别可通过配置调整；`logging.file` 可指定路径

## 修改配置后生效

- 改 `application.yml` → 重启应用
- 生产环境可优先用**环境变量**覆盖敏感项（密码等），避免改文件
