# 01 项目概览与技术栈

> 适用场景：首次接触本项目、搭建开发/部署环境前阅读。

## 项目定位

JeeSite 是一个 **Java EE 企业级快速开发平台**，提供代码生成器、权限管理、工作流、内容管理等开箱即用的基础能力，目标是"一键生成可运行的 CRUD 业务代码"。本仓库是 **V5 版本（Spring Boot 4 技术栈）**。

## 技术栈清单

| 类别 | 技术 |
|---|---|
| 语言 | Java 17+（官方 Docker 镜像用 JDK 21） |
| 框架 | Spring Boot 4 / Spring Framework 6 |
| 构建 | Maven 3.8+（多模块聚合工程） |
| ORM | MyBatis（自研 mapper 体系，XML + 注解混合） |
| 安全 | Apache Shiro（RBAC 权限 + 会话管理） |
| 缓存 | J2Cache（本地 Caffeine + Redis 多级缓存，Redis 可选） |
| Web | Spring MVC + 内嵌 Tomcat |
| 模板（传统端） | Thymeleaf + HTML5 + jQuery |
| 前端（分离端） | Vue 3（JeeSite Vue 工程，独立仓库） |
| JSON | Jackson（tools.jackson 坐标）+ Fastjson |
| 文档 | springdoc/swagger |
| 数据库支持 | MySQL、PostgreSQL、Oracle、SQLServer、达梦、人大金仓、H2 |
| 其它能力库 | POI（Excel 导入导出）、zxing（二维码）、thumbnailator（图片处理）、pinyin4j、BouncyCastle（加解密）、commons-lang3 等 |

## 环境要求

```
JDK：   17 及以上（推荐 21，Ubuntu 24.04 自带 openjdk-21）
Maven： 3.8 及以上
数据库：任选一种（默认配置 PostgreSQL；web-fast 用内嵌 H2 免安装）
```

## 两种前端形态（重要概念）

- **传统全栈端（web 模块）**：后端直接用 Thymeleaf 渲染 HTML 页面，一套 Spring Boot 应用即可运行整个系统。
- **Vue 分离端（web-api / web-vue 模块）**：后端只提供 RESTful JSON 接口，前端是独立的 Vue 3 工程（jeesite-vue 仓库），通过 HTTP 调用 `http://IP:8980/js/...` 接口。

> 本项目用户（Ryan）部署的是 **web-api 模块**（纯接口服务），数据库强制使用 **PostgreSQL**。

## 快速体验

```bash
# 最快跑起来（免数据库，内置 H2）
cd web-fast
./bin/run-tomcat.sh        # Windows: run-tomcat.bat
# 访问 http://127.0.0.1:8980/vue/login ，账号 system / admin
```
