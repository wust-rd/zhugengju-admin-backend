# 03 核心框架与架构

> 适用场景：理解框架设计、定位代码位置、了解权限/缓存/分层架构。

## 一、common 通用工具库（com.jeesite.common）

独立 jar，不依赖业务模块，提供平台级通用能力。主要包结构：

| 包 | 职责 | 典型内容 |
|---|---|---|
| `common.utils` | 核心工具类 | `ObjectUtils`、`StringUtils`、`DateUtils`、`ConvertUtils`、`MyBatisUtils`、`PageUtils`、`PropertiesUtils`、`ExceptionUtils` 等（16 个类） |
| `common.lang` | 语言/对象工具 | 对象转 Map、反射、断言等 |
| `common.codec` | 编解码 | MD5/SHA/AES/RSA 加解密、Base64 |
| `common.idgen` | ID 生成 | 雪花 ID、UUID 生成器 |
| `common.io` | IO 工具 | 文件流、资源加载 |
| `common.image` | 图片处理 | 缩略图、验证码（patchca） |
| `common.media` | 多媒体 | 视频截图等 |
| `common.msg` | 消息 | 邮件发送 |
| `common.network` | 网络 | IP、UserAgent 解析 |
| `common.text` | 文本 | 拼音（pinyin4j）、HTML 处理 |
| `common.web` | Web 工具 | Servlet 工具、请求/响应封装 |
| `common.mapper` | 数据库映射 | `@Table`、`@Column` 等 ORM 注解、查询条件封装 |
| `common.collect` | 集合工具 | Map/List 增强 |
| `common.callback` | 回调 | 事务回调等 |
| `common.exec` | 任务执行 | 线程池封装 |
| `common.reflect` | 反射工具 | 反射封装 |

依赖亮点：Jackson、Fastjson、POI（Excel）、thumbnailator（图片）、zxing（二维码）、pinyin4j、BouncyCastle、UserAgentUtils、commons-lang3/codec/io、logback。

## 二、core 核心业务模块（com.jeesite.modules）

### 包结构

```
modules/sys/        # 系统管理（权限核心）
├── entity/         # 实体类（12 个）：User/Employee/Office/Company/Role/Menu/Area/Post/Log 等
├── dao/            # 数据访问（12 个）
├── service/        # 业务逻辑（14 个）：UserService/EmployeeService/RoleService/MenuService 等
├── web/            # 控制器（28 个）：LoginController/UserController/...（传统端页面+接口）
├── utils/          # 业务工具：UserUtils、EmpUtils 等（部分在 jeesite-framework 依赖中）
├── interceptor/    # 拦截器
└── db/             # 数据库相关（建表脚本等）
modules/biz/        # 业务示例（Entity/Dao/Service/Web 四层）
modules/config/     # 系统参数管理
modules/file/       # 文件管理
modules/msg/        # 消息管理（9 个类）
```

### 分层架构（每层一个包，业务模块统一遵循）

```
Controller (web/)  →  Service (service/)  →  Dao (dao/)  →  Database
        └── Entity (entity/) 贯穿各层作为数据载体
```

- **Entity**：继承 `BaseEntity`，用 `@Table/@Column` 注解映射表结构（通用 mapper 体系，见 `common.mapper`）
- **Dao**：继承 `BaseDao`，对应 MyBatis Mapper 接口
- **Service**：继承 `BaseService`，事务边界所在（`@Transactional`）
- **Controller**：继承 `BaseController`，负责参数校验与请求响应

## 三、权限体系（Shiro + RBAC）

- 核心模型：**用户（User）↔ 角色（Role）↔ 菜单/权限（Menu）**，组织维度：**机构（Office）→ 公司（Company）/部门（Office）**，人员：**员工（Employee）↔ 岗位（Post）**
- 认证：登录认证（传统端表单 / 分离端 token）、记住我
- 授权：基于权限标识（如 `sys:user:edit`）的 URL 与按钮级控制，数据权限（机构范围）
- 常用工具：`UserUtils`（当前用户/角色/菜单）、`EmpUtils`（当前员工/机构）—— 这些类由 `jeesite-framework` 依赖提供

## 四、缓存（J2Cache）

- 默认两级缓存：**本地 Caffeine（L1）+ Redis（L2，可选）**
- 通过 `@Cache` 注解或 `J2CacheUtils` 使用
- 若不用 Redis（本地开发），只需保持缓存配置默认或关闭 Redis 开关即可

## 五、接口风格

- **分离端（web-api）**：RESTful JSON，统一响应结构 `{code, msg, data, ...}`（`Result` 对象）
- **传统端（web）**：返回视图名 + 模板渲染，接口与页面混合
- 参数绑定：通用 `BaseEntity` 查询条件（支持分页 `page`、排序、模糊查询），控制器方法签名约定 `(@RequestBody Entity entity, @Validated @Valid Entity, ...)`
