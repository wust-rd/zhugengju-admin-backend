# 06 部署指南

> 适用场景：把 web-api（或其它 web 模块）部署到 Linux 服务器。

## 部署对象选择

| 场景 | 用哪个模块 |
|---|---|
| 后端 + 传统 HTML 界面一体 | web |
| 后端 + Vue 分离端 | web-vue |
| **只提供 JSON 接口（无界面）** | **web-api**（本项目选型） |
| 快速体验 | web-fast |
| 内部数据服务（极轻量） | web-mini |

> 目标环境：**Ubuntu 24.04 + JDK 21 + Maven + PostgreSQL 16**（本项目实际配置）

## 一、传统方式部署（推荐）

### 1. 安装 JDK + Maven + Git

```bash
sudo apt update
sudo apt install -y openjdk-21-jdk maven git
java -version   # openjdk 21
mvn -v          # 3.8+
```

### 2. 安装数据库（PostgreSQL）

```bash
sudo apt install -y postgresql
sudo systemctl enable --now postgresql
sudo -u postgres psql <<'EOF'
CREATE USER root WITH PASSWORD '123456' SUPERUSER;
CREATE DATABASE jeesite_v5 OWNER root;
EOF
```

### 3. 上传源码

```bash
cd ~
git clone <你的仓库地址> jeesite
cd jeesite
git checkout dev        # 与当前分支保持一致
```

### 4. 检查数据库配置

`web-api/src/main/resources/config/application.yml` 默认就是 PostgreSQL（root/123456/jeesite_v5），**无需修改**。若你改了密码/库名，在此同步修改即可。

### 5. 初始化数据库（仅首次）

```bash
cd web-api/bin
echo | ./init-data.sh
```

### 6. 打包

```bash
./package.sh        # 生成 web-api/maven/web.war（可执行包，内置 Tomcat）
```

### 7. 启动

```bash
mkdir -p ~/logs
cd ../maven
nohup java -jar web.war > ~/logs/web-api.log 2>&1 &
tail -f ~/logs/web-api.log   # 看到 "Started ...Application" 即成功
```

> **重要**：本项目用 PostgreSQL，**不要加 `--spring.profiles.active=prod`**（prod 配置是 MySQL）。

### 8. 验证与开放端口

```bash
curl http://127.0.0.1:8980/js/        # 返回 JSON 即成功
sudo ufw allow 8980/tcp
```

浏览器/前端访问：`http://服务器IP:8980/js/...`

## 二、Docker 方式部署

### 用官方镜像快速体验（不改代码）

```bash
sudo apt install -y docker.io docker-compose-v2
cd ~/jeesite
docker compose -f docker-compose-mysql.yml up -d   # MySQL + 官方 jeesite 镜像
# 访问 http://IP:8980（官方镜像是完整 JeeSite，非纯 web-api）
```

### 构建自己的 web-api 镜像

```bash
# 1. 先打包出 web.war（见上"传统方式"第 6 步）
# 2. 构建镜像（项目自带 Dockerfile）
cd web-api/bin
./docker-build.sh     # 或 docker build -f bin/docker/Dockerfile -t jeesite-web-api .
```

Dockerfile 基础镜像为 JDK 21，启动即运行内置 Tomcat。

## 三、systemd 开机自启（可选）

```bash
sudo tee /etc/systemd/system/jeesite-web-api.service > /dev/null <<'EOF'
[Unit]
Description=JeeSite Web API
After=network.target postgresql.service

[Service]
User=root
WorkingDirectory=/root/jeesite/web-api/maven
ExecStart=/usr/bin/java -jar web.war
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now jeesite-web-api
sudo systemctl status jeesite-web-api
```

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 启动报数据库连接失败 | 检查 PostgreSQL 是否运行、`application.yml` 的 url/账号密码是否正确 |
| 端口被占用 | `lsof -i:8980` 查看，或改 `server.port` |
| 首次 `mvn` 下载依赖慢 | 检查网络，或配置阿里云 Maven 镜像 |
| 8080/8980 访问不了 | 云服务器安全组 + `ufw` 均需放行 8980 |
| `init-data.sh` 卡在等待 | 脚本内有 `read`，用 `echo \| ./init-data.sh` 喂回车 |
| 想部署多个模块 | 不同模块改不同 `server.port`，注意 war 包 finalName 都是 `web`，需分开目录存放 |
