# 05 数据库支持与初始化

> 适用场景：数据库选型、首次初始化数据、重建库。

## 支持的数据库

MySQL、PostgreSQL、Oracle、SQLServer、达梦（DM）、人大金仓（KingbaseES）、H2（内嵌，web-fast 快速体验用）。

## 驱动启用方式

数据库驱动在 `modules/core/pom.xml` 中以依赖形式引入，**MySQL 和 PostgreSQL 驱动默认启用**（runtime 作用域）；其它数据库需自行在 pom 中启用对应驱动并修改 `jdbc` 配置。

## 建库脚本位置

```
modules/core/db/
├── mysql/
│   ├── create_user.sql        # 建用户 jeesite/jeesite + 库 jeesite
│   └── core.sql               # 建表脚本
├── postgresql/
│   └── core.sql               # PostgreSQL 建表脚本
├── oracle/ ...                # 其它数据库
```

表结构与初始化数据由 JeeSite 自动执行（见下），手动只需**建好数据库和用户**。

## 初始化流程（重要）

`init-data.sh` 本质执行：`mvn clean compile` + `mvn test -Dtest=com.jeesite.test.InitData`，自动完成：

1. 连接 `application.yml` 中配置的数据库
2. 执行建表脚本（core.sql，创建 `js_*` 前缀的基础表）
3. 写入基础数据（菜单、角色、初始用户 system/admin 等）

> **安全**：初始化是幂等/增量式的，不会清空已有业务数据。

## PostgreSQL 部署示例（本项目选型）

```bash
# Ubuntu 24.04（自带 PostgreSQL 16）
sudo apt install -y postgresql
sudo systemctl enable --now postgresql

# 创建与默认配置匹配的用户和库（root / 123456 / jeesite_v5）
sudo -u postgres psql <<'EOF'
CREATE USER root WITH PASSWORD '123456' SUPERUSER;
CREATE DATABASE jeesite_v5 OWNER root;
EOF
```

## MySQL 部署示例（官方备选）

```bash
sudo apt install -y mysql-server
sudo systemctl enable --now mysql
# 使用项目自带脚本建库建用户
cd ~/jeesite
sudo mysql < modules/core/db/mysql/create_user.sql
```

## 执行初始化

```bash
cd <web模块>/bin
echo | ./init-data.sh        # echo 用于跳过脚本里的回车等待
```

> 依赖下载 + 建表 + 灌数据，首次执行较慢。看到 `SUCCESS` / 无报错即完成。
